# B · 시뮬레이션

## 2단계 · 내장 Rectangular 기준 실험

교수님 원본의 `QAM32(0)`은 I축에 4개, Q축에 8개 레벨이 있는 32-QAM이다. 원시 좌표의 평균 에너지는 26이고, 실행 시 확인한 정규화 평균 에너지는 1.000000019이다. 내장 배열 인덱스의 5비트 표현을 초기 라벨로 사용했다. 잡음 없이 32개 라벨이 모두 원래 라벨로 복조됨을 실행 시작 시 검증했다. 내장 원시 좌표와 순서는 팀 기준 커밋 `2a5d016`의 `reference/rectangular.csv` 및 `data/constellations.csv`에 들어 있는 Rectangular 좌표와 일치했다. 실행 입력은 내장 배열이다.

비부호화 조건에서 \(E_s=5E_b=1\)이다. 따라서 \(E_b/N_0=\gamma_b=10^{\mathrm{EbN0}_{\mathrm{dB}}/10}\)이면 각 실수축의 분산은 \(N_0/2=1/(10\gamma_b)\)이다. 실행 로그에서 0 dB의 축당 설정 분산이 0.1임을 확인했다. `std::mt19937`을 지점마다 `20261128 + ebn0_db`로 초기화했다. 심볼 인덱스는 균등 분포로 뽑았고 I/Q에는 각각 별도의 영평균 정규 표본을 사용했다.

0~20 dB에서 1 dB 간격으로, 심볼 오류 2,000개 또는 전송 심볼 2,000,000개에 먼저 도달하면 종료했다. 2단계의 [기준 CSV](https://github.com/wngjs8114/Team10_DigitalCommunication/blob/093a60d/results/metrics/simulation_results.csv)는 `Rectangular,initial` 21행이다. 재실행 경로는 `build/rectangular/baseline.csv`이다.

| Eb/N0 (dB) | 전송 심볼 | 심볼 오류 | 비트 오류 | 관측 SER | 관측 BER | 이론 SER |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 0 | 2,927 | 2,000 | 2,773 | 0.683293 | 0.189477 | 0.681672 |
| 10 | 24,255 | 2,000 | 2,060 | 0.0824572 | 0.0169862 | 0.0793914 |
| 15 | 2,000,000 | 1,670 | 1,671 | 0.000835 | 0.0001671 | 0.000792148 |
| 18 | 2,000,000 | 3 | 3 | 0.0000015 | 0.0000003 | 0.00000136237 |
| 19 | 2,000,000 | 0 | 0 | 0 | 0 | 0.0000000528433 |
| 20 | 2,000,000 | 0 | 0 | 0 | 0 | 0.000000000907456 |

각 축의 인접 점 중간까지의 거리는 \(1/\sqrt{26}\)이다. 가우시안 꼬리 확률을 \(q=Q(1/(\sqrt{26}\,\sigma))\)로 두면 4-PAM I축의 평균 오류확률은 \(2(1-1/4)q\), 8-PAM Q축은 \(2(1-1/8)q\)이다. 두 축의 판정이 모두 맞아야 심볼이 맞으므로 이론 SER은 \(1-(1-1.5q)(1-1.75q)\)이다.

19·20 dB의 오류율 0은 각각 200만 심볼에서 관측 오류가 0회였음을 뜻한다. 독립 심볼 오류를 가정하면 각 지점의 단측 95% 이항 SER 상한은 \(1-0.05^{1/2{,}000{,}000}\simeq1.498\times10^{-6}\)이다.

## 3단계 · 내장 성상도 Gray-like 매핑

원본 `QAM32.cpp`에 선언된 네 개의 성상도 배열을 순서대로 읽었다. 배열 인덱스를 `point_id`와 초기 라벨의 정숫값으로 사용했다. 내장 좌표는 원시 평균 에너지의 제곱근으로 나눠 정규화했다. A의 CSV를 입력할 경우에는 각 `point_id`의 5비트 표현으로 시작하고, 입력의 정규화 좌표를 검증한 뒤 그대로 출력한다.

인접 조건은 서로 다른 두 점 사이 거리의 제곱이 해당 성상도의 전역 최솟값과 같을 때이다. 정규화는 한 성상도의 모든 거리에 동일한 배율을 곱하므로 정수 좌표에서 거리 제곱을 비교하면 같은 간선을 정확히 얻는다. \(w_{ij}=\mathbf 1[d_{ij}^2=d_{\min}^2]\)로 두었으며 목적함수 \(J=\sum_{i<j}w_{ij}d_H(b_i,b_j)\)를 최소화했다. 가까운 점은 더 낮은 잡음 크기로 두 점 사이의 이등분면을 넘을 수 있다. 가중치 1은 최소거리 쌍에만 적용하며, 실제 수신점 전이확률은 이 목적함수에 포함하지 않는다.

시뮬레이티드 어닐링으로 두 점의 라벨을 교환했다. 성상도별 시드는 `20261128 + scheme_index`이며, 순서는 Rectangular, Type1, Type2, Type3이다. 초기 매핑에서 한 번, 무작위 순열에서 23번 탐색을 시작했다. 각 시작점에서 최대 12,000번 교환을 시도했고, 온도는 2에서 0.08로 기하급수적으로 낮췄다. 비용이 증가하는 교환의 수용 확률은 \(\exp(-\Delta J/T)\)이다. 초기 매핑을 최우수 후보에 포함했으며, 모든 간선에서 해밍 거리가 1이면 하한에 도달했으므로 종료했다.

| 성상도 | 목적함수 \(J\) 전 → 후 | 평균 인접 해밍 거리 전 → 후 | Gray edge 전 → 후 |
| --- | ---: | ---: | ---: |
| Rectangular | 52 → 52 | 1.0000 → 1.0000 | 52/52 → 52/52 |
| Type1 | 111 → 60 | 2.1346 → 1.1538 | 12/52 → 48/52 |
| Type2 | 119 → 56 | 2.3800 → 1.1200 | 12/50 → 47/50 |
| Type3 | 89 → 55 | 1.8163 → 1.1224 | 25/49 → 43/49 |

Rectangular의 초기 라벨은 \(J=52\)로 하한에 도달했다. Type1~3의 완전 Gray 매핑은 이번 탐색에서 찾지 못했다.

### Type3 공통 표본 검증

Python 3.13.12에서 \(E_b/N_0=10\) dB, 시드 `20261128`, 50,000심볼로 실행했다. 각 표본에서 송신점과 두 축의 AWGN을 한 번 생성하고, 최소 유클리드 거리로 얻은 판정점을 두 매핑에 공통으로 적용했다. 판정점과 송신점이 다르면 심볼 오류 한 개이고, 비트 오류는 해당 매핑에서 두 점의 라벨 간 해밍 거리이다.

| 매핑 | 심볼 오류 / 50,000 | SER | 비트 오류 / 250,000 | BER |
| --- | ---: | ---: | ---: | ---: |
| 초기 | 2,188 | 0.04376 | 3,927 | 0.015708 |
| 최적화 | 2,188 | 0.04376 | 2,490 | 0.009960 |

이 표본에서 관측 BER은 약 36.6% 감소했다. A 최종 좌표의 4종 Eb/N0 비교는 이 문서의 5단계에 있다.

같은 명령으로 재실행한 두 CSV는 바이트 단위로 일치했다. 출력 128행의 원본 좌표와 순서, 라벨 순열, 지표 8행을 독립 재검산했다. `main`의 `data/constellations.csv`로도 입력 경로를 검증했다. `scheme,point_id`로 대조한 128행 전체의 좌표 문자열이 입력과 동일했고, 복제한 `point_id`를 가진 테스트 입력은 거부했다. 입력 버전은 `main`의 `82076e4` 및 2단계에 기록한 교수님 `QAM32.cpp`의 SHA-256을 참조한다.

출력 경로와 실행 명령은 [매핑 실행 절차](../simulation/README.md#gray-like-매핑)를 참조한다.

## 5단계 · A 확정 좌표를 사용한 제출용 실험

A의 인계 커밋 `2a5d016`에 있는 네 성상도의 `data/constellations.csv`, `geometry_metrics.csv` 및 `theoretical_ser.csv`를 사용했다. 각 방식의 32점, `point_id` 0~31, 중복 및 원시 좌표 범위, Type별 홀짝 조건을 확인했다. Rectangular의 좌표와 배열 순서는 교수님 기준 파일과 일치했다. 네 성상도의 평균 심볼 에너지는 허용오차 \(10^{-12}\) 안에서 1이었다. 좌표별 정규화, 원시 평균 에너지, 정규화 계수, 최소거리 및 평균 최소거리 이웃 수를 독립 재계산해 A의 기하 지표와 일치함을 검증했다. 수정할 좌표 행은 없었다.

### SER·BER 결과

비부호화 32-QAM, 균등 심볼, \(E_s=1\), 축별 독립 AWGN, 최소거리 판정 조건이다. \(E_b/N_0\)는 0~20 dB에서 1 dB 간격으로 실행하고, 각 지점은 심볼 오류 2,000개 또는 2,000,000심볼에 도달하면 종료했다. C++ 시드는 `20261128 + ebn0_db`이다. 모든 84쌍에서 두 매핑의 공통 송신점과 잡음으로 복조를 한 번 수행했다. 따라서 전송량, 심볼 오류 수, SER이 정확히 일치한다.

| Rectangular | 24,255 | 2,060 → 2,060 | 0.0169862 → 0.0169862 | 0.0824572 | 0.0810228 |

Type1~3은 0~17 dB 모든 지점에서 관측 BER이 낮아졌다. Rectangular는 같은 라벨을 선택해 전 구간의 오류 수가 같았다. 17 dB에서 Type1~3의 심볼 오류 수는 각각 5, 6, 4회이고, 비트 오류는 각각 12 → 5, 14 → 12, 8 → 4회였다. 이 범위의 차이 크기는 표본이 적으므로 해석에 주의한다. ### 목표 오류율에서의 Eb/N0 차이

각 곡선에서 목표값을 끼우는 인접한 양의 실측값 사이에서 \(\log_{10}\) 오류율을 선형 보간했다. 표의 양수는 오른쪽 매핑 또는 성상도에 필요한 Eb/N0가 더 낮다는 뜻이다.

| 비교 | 목표 \(10^{-2}\) | 목표 \(10^{-3}\) | 목표 \(10^{-6}\) |
| --- | ---: | ---: | ---: |
| SER Rectangular − Type1 | 1.119 dB | 1.166 dB | 계산 제외 |
| SER Rectangular − Type2 | 0.974 dB | 1.023 dB | 계산 제외 |
| SER Rectangular − Type3 | 1.018 dB | 1.061 dB | 계산 제외 |
| BER 최적화 Rectangular − Type1 | 0.921 dB | 0.981 dB | 0.946 dB |
| BER 최적화 Rectangular − Type2 | 0.751 dB | 0.830 dB | 계산 제외 |
| BER 최적화 Rectangular − Type3 | 0.833 dB | 0.892 dB | 0.946 dB |
| BER Type1 초기 − 최적화 | 0.825 dB | 0.517 dB | 계산 제외 |
| BER Type2 초기 − 최적화 | 0.778 dB | 0.503 dB | 계산 제외 |
| BER Type3 초기 − 최적화 | 0.882 dB | 0.544 dB | 0.301 dB |

목표 \(10^{-6}\)에서 계산한 값도 관측 오류가 적은 구간의 추정치이다. 0회 지점을 포함하거나 양쪽 곡선에서 유효한 구간이 없으면 계산에서 제외했다.
