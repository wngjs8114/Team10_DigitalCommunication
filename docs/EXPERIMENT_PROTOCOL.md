# 공통 실험 규격

| 항목 | 규격 |
| --- | --- |
| Scheme | `Rectangular`, `Type1`, `Type2`, `Type3` |
| 변조 차수 | M = 32 |
| 심볼당 비트 수 | k = 5 |
| 평균 심볼 에너지 | 정규화 후 Es = 1 |
| 심볼 발생확률 | 각 심볼 1/32 |
| 기본 채널 | AWGN |
| 기본 수신 판정 | 최소 유클리드 거리 기반 ML |
| 기본 Eb/N0 | 0~20 dB, 양 끝 포함, 1 dB 간격 |

비부호화 조건의 선형 단위에서 Es/N0 = 5 × Eb/N0이다. 복소 AWGN의 I축과 Q축에 각각 독립적인 영평균 가우시안 잡음을 적용하며 각 축의 분산은 N0/2이다.

## 성상도 제한조건

Type1·Type2·Type3의 원본 좌표 I, Q는 모두 −7~7 범위의 정수다. 각 Scheme은 중복 없이 정확히 32개 성상점을 갖는다.

| Scheme | 원본 좌표 조건 |
| --- | --- |
| Rectangular | 교수님이 제공한 기준 성상도 사용 |
| Type1 | I와 Q 모두 홀수 |
| Type2 | I와 Q 모두 짝수 |
| Type3 | I는 홀수, Q는 짝수 |

## 재현성 및 결과 해석

- 실험별 난수 시드, 반복 횟수, 입력 데이터의 Git 커밋 ID 또는 해시를 기록한다.
- 오류 관측 횟수가 0이면 해당 표본에서 오류가 관측되지 않았음을 기록한다. 실제 오류확률이 0이라고 단정하지 않는다.
- 기존 C++ 시뮬레이터의 SNR 정의는 팀원 B가 실제 소스코드를 확인한 뒤 확정한다.
