# Part B · 10조 시나리오 종합

공식 4종의 비부호화 AWGN 오류율과 C의 파형·수신기 분석을 공통 근거로 사용한다. Alarm의 BPSK·QPSK 수치는 동기 검파와 AWGN을 가정한 이론값이다. 96비트 프레임은 전송시간 비교 예시이며, 패킷 실패율과 지연은 별도로 평가한다.

## 공통 질문

1. **Part A의 종합 우수 방식이 세 시나리오 모두에서 가장 좋은가?** Type1은 10 dB에서 공식 4종 중 관측 SER·BER가 가장 낮고, 파형 P99도 가장 낮았다. 정상 Drone과 조건을 충족한 PA 단말에서는 Type1을 선택한다. Alarm은 짧은 메시지의 기한 내 신뢰성을 우선하므로 B가 Gray QPSK를 기본안으로 선택했다.
2. **최적 성상도의 의미는 어떻게 달라지는가?** 목적과 제약에 따라 순위가 달라진다. 공식 32-QAM 안에서도 관측 SER 최저는 0 dB에서 Type2, 10 dB에서 Type1이다. 수신 산술 연산을 최소화하는 기준에서는 Rectangular의 독립 I/Q 판정이 유리하다.
3. **한 지표의 개선은 다른 지표에 어떤 영향을 주는가?** Type1은 Rectangular보다 10 dB의 관측 SER·BER와 파형 P99가 낮지만, 그룹 ML의 연산 부담이 커진다. 같은 성상도에서 라벨만 바꾸면 심볼 판정은 같고 비트 오류 수가 달라진다. Type1의 관측 SER은 10 dB에서 0.040771로 같았고 BER은 0.017780에서 0.009320으로 줄었다. Alarm에서는 QPSK의 이론적 신뢰성 이점을 위해 명목 비트율을 낮춘다.
4. **실제 제품에 추가로 필요한 조건은 무엇인가?** Drone은 비행거리·자세·페이딩·영상 마감시간, Alarm은 동기화·CRC·FEC·간섭에 의한 반복 실패 상관과 전체 지연, PA 단말은 실제 출력 한계·EVM·인접 채널 누설·배터리 소비를 확인한다. 대상 회로에서 처리 지연과 전력도 측정한다.
