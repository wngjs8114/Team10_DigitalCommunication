# 10조 제출 전 검수표

과제 원본 PDF 1–11쪽과 현재 저장소를 대조했다. 상태는 결과 또는 근거가 확보된 **완료**, 근거가 있지만 검증 또는 서술이 더 필요한 **부분 완료**, 자료가 없는 **미완료**, 팀 문서로 조립할 **최종 보고서 통합 필요**로 표시한다. 현재 `report/`에는 검수표가 있으며 단일 제출 보고서는 별도 통합이 필요하다.

## 커밋 전 확인

- 보고서 통합에 필요한 스크립트 `analysis/integrate_final.py`는 현재 미추적 상태다. 저장된 메타데이터의 코드 SHA-256과 일치해 커밋에 포함해야 새 체크아웃에서도 CSV·비교 그래프를 재현할 수 있다.
- 기존 미추적 baseline 실행 파일은 보존했으며 검수 변경 목록과 별개다.
